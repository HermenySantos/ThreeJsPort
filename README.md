## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Vercel

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm test
npm run build
```

## Site

Home: two-column hero, stacked rounded case cards (UN visitor platform → WebAR → live-event AI), also-shipped row, about, and contact. Production deploys from `main`.
