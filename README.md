## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Vercel

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm test
npm run build
```

## Site

Home: two-column hero, stacked rounded case cards (AI → visitor → WebAR → Concierge), about, experience, and contact. Case routes at `/cases/ai`, `/cases/visitor`, `/cases/webar`, and `/cases/concierge`. Production deploys from `main`.
