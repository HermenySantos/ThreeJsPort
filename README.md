## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm test
npm run build
```

## Site

Single-page home: outcome-led hero, WebAR evidence strip, featured visitor platform with a conceptual system illustration, two supporting case studies with expandable contributions, approach, and contact. Client identities and internal operational details are omitted. Production deploys from `main`.
